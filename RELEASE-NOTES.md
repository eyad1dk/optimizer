# EZoptimizer V2.1 — hardware-aware preview

Keeps the compact V2 interface and adds state-based Enable/Disable buttons, category recommendations, Scan PC / Optimize My PC, and shared hardware-aware profiles.

New controls cover CPU boost, memory compression/pagefiles, NTFS TRIM, documented permission policies, optional-service runtime state, active-adapter DNS/RSS/RSC and driver-reported properties. Adds DXGI VRAM inventory, startup-source inspection, network diagnostics/DHCP tools, expanded cleanup and Windows repair commands.

Originals are captured before reversible changes and checked again after apply/restore. Unsupported features are withheld. No security disabling, FPS score or ping promise.

109 regression checks and 612 rendered layouts passed. Native Windows 10 checks covered menu apply/restore, opposite-button recovery, invalid-input feedback, DNS flush and protected scanning. Full native mutation, UAC and Windows 11 certification remain open. Unsigned x64 preview; read docs/V2.1-IMPLEMENTATION.md for the complete feature and test matrix.

Download EZoptimizer.exe or the portable ZIP. Source is available in the repository and source ZIP. SHA256SUMS verifies integrity, not publisher identity.
